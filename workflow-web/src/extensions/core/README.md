# 扩展运行核心

`installer.js` 在应用挂载前验证所有导出、实例化校验器，随后交给 `adapters/` 安装。相同清单重复初始化无副作用；不同清单和安装失败要求整页刷新。

`registries/` 是原有各类型注册表迁入后的唯一实现，保留原查找与版本协议。它们不导入应用入口或业务实现，避免循环依赖。生产注册调用集中在适配器，业务实现只提供被引用的导出。

`catalog.js` 保存纯元数据供查询，不持有第二套可执行组件。`fieldPolicy.js` 从自动生成的平台字段定义读取默认和兼容策略，无需依赖 Vue。

不要在注册阶段调用后端、启动任务或读取某个页面的当前用户/记录。工厂应只创建无业务副作用的实例。底层注册表未提供事务回滚，安装异常会阻止应用继续挂载。
