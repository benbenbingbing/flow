## 使用体验与剩余范围

- 配置未绑默认表单时，SLA 选项在面板中仍保留选中态，但“应用到画布”失败且 XML 无 SLA 配置；建议以明显的未应用标识提示前置条件，并把错误定位到阻塞项。
- SLA 监控表格在 1280px 页面宽度下列较多，业务编号、策略和流程 key 折行，右侧响应/办结列需要水平滚动；建议冻结关键列并为代码值提供悬浮完整内容。
- 按用户最新要求，本轮在当前 SLA 场景闭环后停止新增测试；知会、自动跳过、多人办理均未测试，不应标为通过。
