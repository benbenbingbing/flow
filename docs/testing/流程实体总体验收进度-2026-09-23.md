## 已修复的问题和待复测处

- 流程节点类型替换、撤销、重做后，配置面板标题及类型曾停留在旧节点；已修正选中节点同步逻辑，网关代理已在页面复测类型替换和撤销/重做。
- 关系数据键是否保留 `title` 曾被误判；已恢复允许 `title`，并以实际保留的 `processInstanceId` 做校验用例。此项未作为新功能保留。
- 实体新增字段的 DDL 预览曾丢失自定义列名、默认值、长度/精度信息；现根据完整字段模型生成预览。后端已重启，仍需在实际页面对新增字段逐类型复测。
- 系统 `status` 字段元数据预览曾显示 `varchar(20)`，而实际 DDL 是 `VARCHAR(50)`；已统一新增实体元数据，并新增 V103 修正旧元数据。迁移已执行，旧实体页面回显 50 已由关系代理复测。
- 列表默认排序与完整 CSV 导出顺序、表单最小值、自定义校验器、唯一性失焦预检与编辑排除自身、字段标签/占位/编辑权限，已由表单列表代理在实际页面复测并恢复临时配置。固定条件 `金额≥2` 与用户查询的交集曾错误；修复后实际页面验证 `=1` 返回 0、`=2` 返回 1、重置返回 5，临时条件已移除并重新发布。
- 关系必填、父子级联删除、一对一/一对多双外键、可选一对一留空不生成子记录、一对一移除后多项保留，已由关系代理通过真实页面及数据回显验证。
- 停用关系并发布实体后，旧版表单仍可填写该子项，原提交触发父表不存在列的 SQL 错误。已修正关系键处理及写前失配校验；真实页面重试得到明确的“关系未在当前实体版本启用”提示，弹窗保留，父列表无新增，也没有 SQL 500。测试关系已重新启用并发布实体 V4。旧表单仍允许填写停用子项属于未解决的操作体验问题。
- 流程并行任务列表显示与实际提交节点不一致已修复；网关代理在同一并行实例中按任务 ID 办理两个分支，实际页面最终显示完成。包容网关单命中/双命中与 OR 字符串条件已测；零命中无默认流时运行失败且无部分数据。发布预检修复已在页面复测；添加默认路径的 V4 发布后，零命中实例沿默认连线直接结束，图上实际高亮路径正确。

## 未完成范围

625 项配置清单仍有大量未实测项，尤其是其余 BPMN 节点类型与条件组合、知会/自动跳过/多人办理、实体数据版本的关联范围与容量上限、表单联动与自定义组件、列表虚拟列、权限的行级规则、默认事件运行触发与回滚。低权限 `lisi` 已在独立 Safari 页面验证受限列表显示权限不足，两个相关接口返回 403；行级规则仍待测。尚未形成闭环的项目不能仅凭单元测试或配置回显判为通过。

当前已执行场景未留有确认仍未修复的功能缺陷。表单弹窗快速切换时的旧金额瞬态与长时间停留页面后的令牌过期提示尚未稳定复现，分别记为 F-01/F-02 待确认，不标记为已修复。已确认但仅记录建议的体验问题包括：旧表单展示已停用关系直到提交才报失配、SLA 未满足前置条件时面板仍保留选择态、只修改忽略字段时版本比较突出显示系统更新时间、并行网关连线面板仍显示条件配置入口，以及窄屏监控表格可读性。
