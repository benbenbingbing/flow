# ADR-0010 按调用场景划分契约目录

- 状态为已接受
- 日期为 2026-11-23
- 补充 [ADR-0009](0009-flatten-platform-port-packages.md) 的一级目录规则。

> 当前目录和包名见 [ADR-0011](0011-platform-port-namespace.md)。

## 背景

接口平铺后，业务开发者仍需在身份、字典、设置及历史等一级目录之间判断应去哪里查找。一级目录需要对应调用者能识别的业务场景。

## 决策

- `system` 集中提供身份、组织、字典、权限与设置，以及系统实体读取。业务模块按各接口原有授权调用。
- `entity` 面向业务记录、表单、关系、实体版本与提交，`process` 面向实例、任务、办理历史与干预。
- `migration` 负责配置迁移、历史导入和导入后的流程档案。字典的日常读取归 `system`，迁移时应用字典归 `migration`。
- `embed` 负责嵌入式接入。`platform` 集中提供审计、启动、执行预算和事务事件发布。
- 接口平铺在每个场景的 `port` 包。配套类型跟随场景保留各自的职能子包。README 同步提供按场景的导航与全部接口的读写索引。

## 影响

Java 调用方和实现使用新包名并一起重新编译。原有身份扩展编码、审计事件、归档数据和 Outbox 主题继续使用既有标识。仓外扩展如引用受影响的类型，需要重新编译并依照现有发布规则验证制品。
