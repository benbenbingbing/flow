# ADR-0009 按模块平铺平台 Port

- 状态为已接受
- 日期为 2026-11-23
- 决策范围为 `workflow-port`，更新 [ADR-0006](0006-contract-package-boundaries.md) 的 Port 包规则。

> 当前六个一级目录见 [ADR-0010](0010-group-platform-contracts-by-use.md)。

## 背景

同一个模块的接口散在多个功能包里。开发者需要先知道某项能力属于哪种流程任务、实体表单或运行时场景，才能找到接口。部分接口同时支持查询与变更，单看接口名无法判断调用的副作用。

## 决策

- 顶层 Port 统一位于 `com.workflow.contracts.<domain>.port`，一个接口对应一个文件。
- 配套模型、错误与上下文沿用各自的功能包。扩展契约继续沿用 `<domain>[.<feature>].spi`。
- 新的纯查询和纯变更接口分别采用 `QueryPort` 和 `CommandPort`。已有接口沿用原名。混合接口的 JavaDoc 写明各方法的读写属性与事务副作用。
- 模块 README 为每个 Port 提供源码链接、读写类型、用途和适用调用方。架构测试校验接口位置及索引覆盖。

## 影响

调用方和实现类需要一起更新 import 并重新编译。外部扩展使用迁移类型时需要同步升级。发布前按既有流程核对已钉定的扩展制品摘要，使用正确的实现版本。接口方法、接口内嵌类型和模型归属沿用现有契约。
