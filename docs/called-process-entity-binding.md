# 调用已有流程作为子流程

在设计器中选中内嵌子流程，将「子流程来源」改为「调用已有流程」，选择其他已发布流程。
也可以从左侧工具栏直接创建「调用已有流程」节点。

打开「关联实体记录」，在「记录 ID 来源」中选择父实体字段，或输入父流程参数引用，
例如 `${relatedRecordId}`、`${relation.id}`。记录来源只支持变量与对象路径，不执行方法或脚本。
所选流程必须唯一绑定一个实体，传入的 ID 必须属于该实体，且该记录尚未发起流程。

点击「应用到画布」后，再保存草稿、校验并发布。内嵌节点转换时保留节点 ID、外部连线和
节点配置，原内部节点由被调用的流程替代；可以通过设计器撤销恢复。

运行时使用目标实体记录中的业务字段、表单、审批配置及状态规则。发起人沿用父流程的
可信发起人，参数映射继续生效；输入参数可覆盖同名业务变量，不能覆盖实体身份和平台保留变量。
父流程等待子流程结束，再沿原连线继续。输出参数仅回传明确配置的变量。

记录不存在、已有关联流程、目标流程被禁用或出现循环调用时，当前流转事务失败回滚，
不会留下半启动的子流程。已有内嵌子流程和未启用「关联实体记录」的旧调用活动保持原行为。

本次没有数据库迁移；配置保存在 BPMN 的 `callConfig` 扩展属性中。
