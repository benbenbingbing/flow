# 实体 Excel 导入导出使用说明

Excel 的列、格式和校验规则在实体上配置；表单和列表通过按钮使用这些配置。一个实体可以维护多套方案，并分别指定默认导入方案和默认导出方案。每套方案内分为“导入设置”和“导出设置”，两边可以使用不同的列、标题、顺序和转换规则。普通使用者点击按钮即可使用已配置的方案，无需临时选择方案。

本说明按当前界面和实现编写。已完成后端单元、事务、迁移与架构检查，以及前端组件回归和构建验证。浏览器组件回归使用模拟 API；真实业务环境的前后端联调尚未执行。

## 1. 创建并发布方案

入口：**实体设计 → Excel 导入导出 → 方案管理**。当前系统实体不显示此页签。

1. 先发布实体字段。导入还需要一个属于同一实体、已启用且已发布的写入表单；该表单决定每条新增记录的提交规则。
2. 点击“按实体字段生成方案”，或点击“新增方案”手动添加列。生成结果仍是待编辑草稿，需要检查字段、必填项和转换规则。
3. 填写共用的“方案编码”“方案名称”和“说明”。编码以字母开头，只包含字母、数字和下划线；保存后编码不可修改。
4. 在“导入设置”中勾选“启用导入”；需要作为默认导入方案时，同时勾选旁边的“是否默认”。在“导入文件”中配置“导入 Sheet”和“最多数据行”（最高 1000 行）；在“批量新增”中选择已发布的“写入表单”及旁边的“未知列”策略，再编辑导入列和附加校验。首版固定一行表头，第一行为标题，第二行开始填写数据；工作表名称必须与“导入 Sheet”一致。“未知列”默认“直接插入”，也可选择“拒绝并报告”或“忽略额外列”，悬停标签旁的问号可查看说明。
5. 切换“导出设置”，勾选“启用导出”；需要作为默认导出方案时，勾选此页签的“是否默认”。配置“文件名规则”“导出 Sheet”、导出列及列宽。例如文件名 `员工_{yyyyMMdd}`；支持 `{yyyyMMddHHmmss}`、`{yyyyMMdd}`、`{yyyy-MM-dd}` 日期占位符，输出为 `.xlsx` 文件。导出设置中的列标题、顺序及格式可单独调整。
6. 可以只启用一个方向。暂时关闭某个方向会保留该方向已编辑的配置，重新启用后可继续使用。
7. 检查两个页签后点击共用的“保存草稿”。回到方案列表，点击该方案的“发布”。两个方向属于同一套方案，一起保存、发布；只有发布成功且处于启用状态的方案才能运行。

“保存草稿”允许暂缺部分配置；“发布”会检查字段是否存在于已发布实体、写入表单、列映射和转换规则等。保存草稿不会改变当前运行规则。

### 列映射与转换

每个页签都有独立的列映射，从上到下就是该方向的文件列顺序，最前方显示 A、B、…、Z、AA、AB 等 Excel 列序号，拖拽序号旁的把手调整顺序；也可聚焦把手后用键盘方向键调整，用“添加列”“移除”决定该方向包含哪些列。同一字段可以分别出现在导入列和导出列中；修改一边的标题、顺序、转换规则或增删列，不会同步修改另一边。导入模板使用导入设置中的列。

| 配置 | 用法 |
| --- | --- |
| 字段 / 列标题 | 选择实体字段，再设置 Excel 中展示的列标题。 |
| 所属方向 | 在“导入设置”中添加的列用于导入和模板；在“导出设置”中添加的列用于导出。 |
| 文本 | 可去首尾空白。工号、编号等有前导零的值应在 Excel 中按文本填写。 |
| 日期 / 日期时间 | 分别用于实体日期、日期时间字段。导入配置主要日期格式和允许输入的日期格式；导出配置输出日期格式和显示时区。时区用于转换时间点，Excel 本地日期时间保持原值。 |
| 金额 | 两个方向分别设置小数位数和舍入方式；默认“禁止隐式舍入”。导出中的“按文本保留精度”适合需要准确保留金额的文件。 |
| 字典代码 | 使用实体字段已绑定的代码表；导入页选择名称、代码或两者，导出页选择名称或代码。两边分别保存转换方式。 |
| 数字 / 布尔值 | 用于对应字段类型的基本转换。 |
| 实体关联 | 支持单选、多选实体。导入默认按编码或名称精确匹配，可选择目标实体的其他基础属性；导出默认名称，也可选择其他属性。 |
| 实体状态（导出） | 仅用于系统 `status` 字段，可导出实体状态名称或原编码；无需绑定代码表。 |
| 附加校验（导入） | 可设置必填、文件内唯一、最小值、最大值；写入表单未配置的字段按“未知列”策略处理，实体保存约束仍生效。 |
| 列宽 | 导入页的“模板列宽”决定下载模板的显示宽度；导出页的“导出列宽”决定导出文件的显示宽度，两边分别设置。 |

按实体字段生成方案时，会自动填好字段、列标题和转换规则，并为两个方向分别生成可编辑的列。“数据名称”“数据编码”虽然属于系统标准字段，也会纳入预置；其他内部系统字段、不可读字段、附件及子表等未支持的复杂字段会跳过；单选和多选实体会生成“实体关联”转换规则。只读业务字段仅生成导出列。日期按字段类型预填格式，金额沿用实体小数位数（未配置时为 2 位），字典默认导入名称或代码、导出名称；导入还会带出实体的必填和唯一约束。生成后仍需填写方案编码、名称并选择写入表单，检查后保存、发布。若业务必须填写某个未生成的字段，应检查实体默认值、编码生成规则或手动补充支持的列，不能仅通过取消方案中的“必填”绕过实体校验。

### 导出实体状态名称

在“导出设置”中添加或选择“状态（status）”列，转换规则选择“实体状态”，导出方式选择“导出名称”。保存草稿并发布方案后，导出文件会使用当前实体配置的状态名称；未配置时使用系统内置名称，仍无法识别的历史状态保留原编码，空值保持为空。选择“导出代码”则直接输出状态编码。

新选择系统 `status` 字段时默认使用“实体状态 / 导出名称”。已有方案的文本或字典配置不会自动替换，需要手动切换转换规则并重新发布。实体状态无需绑定普通代码表；“字典代码”仍用于绑定了代码表的业务字段。

该转换仅用于系统 `status` 字段导出，不用于导入，也不适用于独立的“流程状态（processStatus）”字段。

### 写入表单与未知列

“未知列”指**实体中存在、已在 Excel 方案的导入列中映射，但所选写入表单没有配置的字段**。例如实体有“姓名、备注”，方案也映射这两列，而写入表单只配置“姓名”，则“备注”属于此处的未知列。

| 未知列策略 | 导入行为 |
| --- | --- |
| 直接插入（默认） | 按 Excel 方案转换和校验该字段，通过后作为普通字段保存，不执行该字段的表单规则；实体必填、唯一等保存约束仍执行。 |
| 拒绝并报告 | 方案中存在这些导入列时，列出字段并阻止导入或模板下载，需调整方案或写入表单。 |
| 忽略额外列 | 跳过这些字段的文件输入和 Excel 规则，模板也不包含它们；实体正常默认值与保存约束仍生效。如果所有导入列都被忽略，则提示调整配置。 |

此处的策略不开放任意字段写入：字段仍须存在于实体、受支持并配置在方案的导入列中。文件中根本没有映射到方案的额外表头不属于此处的“未知列”；开启“校验表头”时，额外或缺失的列以及列标题、顺序不一致均会报错；关闭时按方案位置读取，额外表头不参与字段匹配。

### 批量新增选项

| 配置 | 默认值 | 生效方式 |
| --- | --- | --- |
| 文件大小限制 | 10 MB | 在“导入文件”中设置每个文件的大小上限，可配置 1～50 MB。选择文件、正式导入及预校验均执行同一限制；1 MB 为 1024 × 1024 字节。历史方案缺省时使用 10 MB。 |
| 校验表头 | 打开 | 文件标题、列数和列顺序必须与当前方案模板一致，否则返回导入错误。关闭后按方案列位置读取，不根据标题匹配字段。 |
| 空行截止 | 打开 | 数据区遇到第一条整行为空的行即截止，后面再有数据也不导入；关闭后跳过空行并继续。 |
| 提交条数 | 100 | 每累计指定条数的待保存数据提交一次，可配置 1～1000；最后不足一批仍提交。已提交的批次保留。 |
| 返回未导入数据 | 打开 | 提供未导入数据下载，原行内容保留，追加“行数”和“原因”两列。包括错误行、空行截止后的数据及停止后未处理的数据；已保存行不在报告中。关闭后仍显示错误摘要，但不生成报告。 |
| 启用预校验 | 打开 | 导入面板显示“预校验”，只检查数据、不保存；关闭则仅提供正式导入。 |
| 失败策略 | 停止返回 | 遇到首个数据错误停止后续导入；选“继续执行”时收集错误并处理剩余记录，完成后统一返回。无法读取文件、表头不匹配等文件级错误均立即停止。 |

调整方案并保存、发布后采用分批提交。无论选择哪种失败策略，已经成功提交的批次都不会因后续错误撤销。发生部分成功时，请根据“实际新增”和未导入报告确认结果，修正后仅重新上传未导入的数据，避免重复新增。

### 单选、多选实体的导入导出

选择 `REFERENCE`（单选实体）或 `MULTI_REFERENCE`（多选实体）字段后，转换规则为“实体关联”。目标实体由源字段的已发布定义决定，不能在 Excel 方案中另选一个实体；关联目标也需要先发布。匹配和输出属性只列出可读基础属性，不支持递归展开关联、附件、子表或敏感字段。

- **导入匹配属性**：默认选择“编码、名称”，可增加或改为 ID、邮箱等目标属性，最多 10 项。每个值在所有选中属性上做精确匹配，命中的记录 ID 去重后必须只有一个；同一条记录同时命中编码和名称可以通过，命中不同记录则报错，不按选择顺序优先取第一条。数字按数值比较，日期使用 `yyyy-MM-dd`，日期时间使用 ISO 本地时间；字典属性在此处匹配原代码，不额外转换字典名称。
- **导出内容**：默认“名称”，可选择编码、ID 或其他可读基础属性。实际输出所选属性的值；属性为空、关联记录已删除或当前用户无权读取时会明确报错，避免导出缺失关联信息。想让导出的文件再次导入，应把该导出属性也加入导入匹配属性，并保证能够唯一确定记录。
- **多值分隔符**：只有多选实体显示，默认英文分号 `;`，也可选换行。比如 `C001;C002` 可匹配两条记录。值内的分隔符和反斜杠以反斜杠转义，例如名称 `甲;乙` 填写为 `甲\;乙`；导出自动添加转义。重复引用同一条记录会按首次出现顺序去重；空项、末尾分隔符或未完成的转义会报错。
- **失败与保存**：找不到记录、无权访问、重名或格式错误会按原文件行列报告，并沿用方案的批次和失败策略。导入只关联已有记录，不创建目标记录；单选传递 ID，多选传递 ID 数组到原表单保存流程。表单处理后还会复核最终 ID 的存在性和访问权限。

例如目标客户有 `C001 / 客户甲 / a@example.com`：默认可以填写 `C001` 或 `客户甲`；导入匹配属性选择邮箱后，可填写 `a@example.com`。导出内容选择邮箱时，该列输出 `a@example.com`。所有查询沿用目标实体的读取权限及数据权限，不会因具有源实体的 Excel 权限而自动获得目标记录权限。

### 已有方案兼容

旧方案中同时参与导入、导出的列，打开编辑时会分别出现在两个页签，初始标题、格式和顺序与旧配置一致。此后可独立修改；保存并重新打开后，两边的配置分别保留。原有仅导入或仅导出的列仍出现在对应页签。

旧草稿中两个方向都未启用的列会显示在“未启用的历史列”中，可点击“用于导入”或“用于导出”恢复到相应页签，补齐字段、标题等配置；不再需要的列可直接“移除”。

旧方案未设置表单“未知列”策略时按“直接插入”处理，后续可在写入表单旁调整；旧方案针对文件额外表头的“拒绝”或“忽略”配置仍保留在文档中。新保存的方案采用上述表头开关与分批策略；未重新保存、发布的历史方案按原发布配置执行。

方案编码、默认方案选择以及按钮中的“指定方案”引用继续使用原方案。保存草稿后仍需发布，新的配置才会用于后续导入导出。

## 2. 设置默认方案

入口：**实体设计 → Excel 导入导出 → 新增或编辑方案**。

1. 在“导入设置”或“导出设置”中，勾选“启用”旁边的“是否默认”。两个方向分别选择，可以使用同一方案或不同方案；每个方向只能有一个默认。
2. 点击“保存草稿”，回到方案列表后发布该方案。方案内容和该方案的默认选择一起生效，无需再到列表上方单独设置、发布默认配置。
3. 查看方案列表“默认”列中的“默认导入”“默认导出”标记，确认当前生效的默认方案。只保存草稿不会改变运行中的默认入口。
4. 需要更换默认时，编辑另一方案并勾选相应方向的“是否默认”，保存并发布新方案即可。复制方案不会继承默认身份。

取消某个方案的“是否默认”并发布后，该方案不再作为对应方向的默认；如果该方向没有其他已发布默认方案，默认按钮将不可用。关闭导入或导出时，会同时取消该方向的默认勾选。指定方案的按钮继续使用其指定方案，已有显式引用仍会阻止关闭它所需的操作能力。

发布当前方案不会顺带发布其他方案的默认草稿。修改已有方案的列或格式后，也要再次发布该方案。方案列表的“引用”可查看使用位置；被引用的方案需先解除引用才能删除。停用方案会影响使用它的按钮。

## 3. 使用列表默认按钮

入口：**列表设计 → 工具栏按钮**。

默认按钮使用实体上当前已发布的默认设置，不需要配置 Excel 事件链。

| 内置按钮 | 使用方案 | 操作范围 |
| --- | --- | --- |
| 导入 | 默认导入方案 | 文件中每一行新增一条实体记录。 |
| 导出选中 | 默认导出方案 | 当前勾选的记录；没有勾选时不可执行。 |
| 导出全部 | 默认导出方案 | 当前筛选下的全部匹配记录，不限当前页，并受列表固定条件和数据权限约束。 |

**内置“导入”默认不启用。** 新建和已有列表打开设计器时，工具栏按钮中都会显示这条内置按钮；勾选该行“启用”，保存按钮并发布列表即可使用。已有导入按钮的启用状态会保留。仅打开设计器或设置实体默认方案，不会自动开放业务页面的导入入口。

“导出选中”“导出全部”也需要在列表中启用。默认方案未发布、已停用或当前用户无相应权限时，按钮可能禁用或不可见；可见的禁用按钮会提供原因。

本期表单通过自定义按钮使用 Excel；表单的“保存”“提交”等平台默认按钮不承担 Excel 导入导出。

## 4. 配置自定义按钮

### 表单入口

在表单设计器打开 **表单设置 → 按钮与操作 → 自定义按钮 → 添加按钮**。设置按钮名称、编码、权限和适用模式，执行方式选择“业务接口 / 事件链”。先保存表单草稿，再点击按钮对应的“事件链”。

新增的表单自定义按钮默认停用，配置完成后需启用。用于导入时，关闭按钮设置中的“执行前校验”，避免当前表单未填写的字段阻止批量导入；导入文件仍会按方案指定的写入表单校验。

### 列表入口

在 **列表设计 → 工具栏按钮** 或 **操作列按钮** 中点击“添加自定义按钮”，把执行方式设置为“自定义 / 业务接口”，保存按钮后点击“配置事件链”。

列表操作列的行按钮支持当前行导出和模板下载，首版不提供行按钮批量导入。

### Excel 操作快捷配置

在事件编辑器中展开“Excel 操作快捷配置”。若从列表公共事件入口进入，先选择“目标按钮”。

1. 选择“操作”：“Excel 导入（批量新增）”“Excel 导出”或“下载导入模板”。
2. 设置“方案选择”：

   | 界面选项 | 配置值 | 生效规则 |
   | --- | --- | --- |
   | 跟随实体默认 | `DEFAULT` | 导入和模板使用默认导入方案；导出使用默认导出方案。方案内的默认选择发布后，后续操作自动跟随。 |
   | 指定方案 | `EXPLICIT` | 选择一套支持当前操作的已发布方案。更换实体默认设置不影响该按钮；该方案自身重新发布后，后续操作使用其最新发布内容。 |

3. 导出操作还需选择“数据范围”，见下一节。
4. 点击“保存 Excel 事件绑定”，随后发布所属表单或列表。保存事件绑定本身不会执行导入导出，也不会自动发布页面。

快捷配置会保留按钮已有的其他前后处理步骤。若提示按钮已有业务主处理，应先在事件链编辑器中明确调整，不能给同一按钮增加两个主处理。

Excel 快捷配置使用平台内置动作：操作类型、方案引用和导出范围直接保存在当前按钮的事件绑定中，不会为每个按钮新增扩展接口。不同按钮的参数互相独立，修改后须发布所属表单或列表才生效；方案本身仍在实体中统一维护。

历史版本生成的 Excel 扩展接口绑定仍可使用。在快捷配置中重新保存时，当前按钮会转为内置动作，原接口保留以兼容其他引用和已发布页面。通用事件编辑器会将新步骤显示为“内置 Excel 操作”，参数通过 Excel 快捷配置调整。

## 5. 选择导出范围

| 按钮位置 | 可配置范围 | 使用方法 |
| --- | --- | --- |
| 列表工具栏 | 选中记录、当前筛选结果 | 先在当前列表勾选或完成筛选，再点击按钮。 |
| 列表行按钮 | 当前已保存记录 | 只导出所在行。 |
| 表单按钮 | 当前已保存记录 | 导出正在查看或编辑的已保存记录；未保存的新增记录不可导出。 |
| 表单按钮 | 选中记录、当前筛选结果 | 配置“来源列表”，运行时打开该列表供用户选择或筛选。 |

表单批量导出必须选择同实体的已发布“来源列表”。运行时使用这个列表的当前发布配置及数据权限，不读取其他页面残留的选择。

- 选择“选中记录”时，在弹出的列表中勾选后点击面板底部的“确认导出”；没有勾选时按钮禁用。
- 选择“当前筛选结果”时，在弹出的列表中设置并执行查询，再点击“确认导出”。会导出全部匹配记录，不限当前页。
- 打开选择列表本身不会触发导出。

所有导出入口都先打开确认面板，包括列表的“导出选中”“导出全部”和表单导出。点击面板底部的“确认导出”才生成文件；直接关闭面板不会创建导出任务。执行中按钮不可重复点击，成功后点击“下载 Excel”下载文件，文件名和工作表格式使用方案设置。

## 6. 下载模板、校验与导入

1. 点击列表“导入”或已配置的导入自定义按钮，打开“Excel 批量新增”弹窗。
2. 点击上传区域右侧的“下载导入模板”链接按钮。如果另设了“下载导入模板”按钮，也可以直接下载同一方案模板。
3. 保留模板表头和工作表名称，从第二行开始填写，每行对应一条新增记录。
4. 点击上传组件中的“选择 Excel 文件”，选择 `.xlsx` 或 `.xls` 文件；大小上限显示在上传区，默认 10 MB。可移除或重新选择文件。
5. 方案启用预校验时，可先点“预校验”，检查文件转换、实体和写入表单校验结果。这一步不保存记录，也不自动开始导入。
6. 点击“上传并导入”，服务端会重新校验，并按提交条数和失败策略保存，无需额外的保存确认。此前“预校验”通过不替代正式导入时的检查。
7. 查看“实际新增”和结果说明。成功后相关页面会收到刷新通知，同一文件的导入按钮被禁用；重新选择文件表示发起新的导入。

表单上的导入按钮同样用于批量新增实体记录，不把文件内容回填到当前表单，不提交当前表单未保存的内容，也不自动发起流程。

“使用方案”和导入执行说明默认隐藏。需要排障时，连续三击弹窗标题可显示这些信息；再次三击可收起，重新打开弹窗后恢复隐藏。

## 7. 错误、过期和重试

文件未通过校验时，结果显示工作表、文件行号、列、字段和错误原因，可分页查看。表头、空文件等错误可能属于文件级错误，并不对应某条数据记录；不能仅凭“失败行数为 0”判断导入成功。

启用“返回未导入数据”且有未导入行时，可点击“下载未导入数据”，文件追加“行数”和“原因”并保留原行内容。修正未导入的数据后重新选择文件，再校验或导入；已经保存的行不要重复上传。错误数量达到收集上限时，界面会说明结果已截断。

网络中断后，应保留当前弹窗和已选文件，直接再次点击相同操作。前端复用该次请求标识，服务端返回同一任务，避免重复新增。“预校验”和“上传并导入”是独立操作；关闭重开、刷新页面或重新选择文件会开启新的操作，不能把重新上传当成同一任务的网络重试。导入结果不确定时，应先恢复当前请求或核对业务记录。

导出请求失败时，面板底部的按钮变为“重试导出”。相同条件重试复用当前请求，改变选择或筛选则创建新的导出。任务仍在处理时可点击“刷新状态”。

任务文件和错误明细保留 24 小时。过期后页面提示保留期已结束，不再提供已清理文件的下载；下载过程中刚好过期也会显示具体原因。导出文件可重新执行生成；导入报告过期不表示记录被删除，不应仅为重新获取报告重复执行已成功的导入。

若提示操作上下文、方案或页面配置已变化，应关闭当前操作，重新打开来源页面和按钮，以最新已发布配置执行。配置保存发生版本冲突时，重新加载并核对其他人的修改后再保存。

## 8. 首版边界

| 项目 | 当前范围 |
| --- | --- |
| 导入文件 | `.xlsx` / `.xls`，默认每个文件不超过 10 MB，方案可配置 1～50 MB；同时受部署的上传请求上限约束。 |
| 导入行数 | 最多 1000 条数据行，方案可以设置更低上限。 |
| 文件结构 | 指定工作表、单行表头；第二行起为数据。 |
| 写入方式 | 仅新增，不按工号等业务键更新或覆盖已有记录。 |
| 事务 | 新保存并发布的方案按提交条数分批保存；已提交数据保留，数据失败按停止或继续策略处理。未重新发布的旧方案保留其原事务策略。 |
| 字段 | 文本、数值、日期、日期时间、布尔、支持的单值代码字段，以及单选/多选实体关联；不处理附件、子表的批量写入。 |
| 流程 | 不自动发起流程。 |
| 导出 | `.xlsx`；受列表条件、数据权限及服务端导出上限约束。 |

## 9. 示例：员工资料

假设“员工”实体已发布以下字段，并有已发布的“员工新增”表单：

| 字段 | Excel 标题 | 转换与规则 |
| --- | --- | --- |
| `employee_no` | 工号 | 文本、必填、文件内唯一；例如 `000123` 按文本填写。 |
| `employee_name` | 姓名 | 文本、必填。 |
| `hire_date` | 入职日期 | 日期，格式 `yyyy-MM-dd`。 |
| `salary` | 薪资 | 金额，2 位小数，禁止隐式舍入，导出按文本保留精度。 |
| `employment_status` | 在职状态 | 绑定员工状态代码表，导入名称或代码，导出名称。 |

创建 `employee_basic` 方案，在“导入设置”中启用导入并选择“员工新增”作为写入表单，在“导出设置”中启用导出，并分别勾选两个页签的“是否默认”，检查列配置后保存并发布。例如导入使用“工号”标题，导出可单独改成“员工编号”并调整顺序，导入模板保持“工号”。随后在员工列表启用内置“导入”，保存并发布列表，即可下载模板并批量新增员工。

若财务需要不同列，可复制方案为 `employee_finance`，调整列后发布；在列表添加“财务导出”自定义按钮，选择“Excel 导出 → 指定方案 → 财务方案 → 当前筛选结果”，保存绑定并发布列表。员工列表的默认导出继续使用 `employee_basic`，财务按钮使用 `employee_finance`。

## 10. 开发与部署说明

数据库升级新增 `V115__entity_excel_configuration_and_jobs.sql`，由 Flyway 按版本顺序正常执行，无需改写历史迁移。已有环境的权限升级作业会自动为管理员、超级管理员补齐实体 `import` 权限；业务角色需要按实际职责授权。

导入、导出编辑拆分沿用 `schemaVersion: 1` 方案协议和现有接口。编辑器将旧 `columns` 按方向展开，保存时仍写回 `columns`，每列带有对应方向标记和全方案唯一 `key`，各方向内部顺序分别保留。本次编辑界面调整不需要新增数据库迁移；历史方案无需批量转换，编辑保存时自动兼容。

写入表单旁的“未知列”保存为 `importConfig.unknownColumnPolicy`，支持 `DIRECT`（默认）、`REJECT`、`IGNORE`。缺少该属性的旧方案默认 `DIRECT`；原 `file.unknownColumnPolicy` 保留兼容值，不复用为表单字段策略。新增 `importConfig.validateHeader`、`stopAtEmptyRow`、`batchSize`、`returnUnimported`、`precheckEnabled`、`failurePolicy` 分别保存上述六项设置；本编辑器保存时使用 `transactionPolicy: BATCH`。本次新增策略沿用 JSON 方案文档，不需要数据库迁移。

私有任务文件使用 `entity.excel.file-secret` 加密；未设置时依次回退到 `entity.excel.action-secret`、`ui.release-resolution.secret`、`jwt.secret`。同一环境的所有实例必须使用一致密钥，任务文件的 24 小时保留期内保持密钥不变，避免已有文件无法解密。

配置迁移包携带已发布的 Excel 方案、默认设置及按钮依赖，目标环境按 `entityCode`、`schemeCode`、`formKey` 重建关联；不携带源环境的 Excel 本地 ID、运行任务、上传/导出文件或业务行数据。迁移沿用预检与冲突检查，配置元数据沿用既有事务，表结构发布沿用项目现有的 DDL 执行及结构台账机制，不将表结构变更表述为全包可回滚。依赖缺失或正常发布校验不通过时应先处理阻断项；Excel 批量数据导入按方案的批次和失败策略独立执行。
