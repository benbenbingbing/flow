# 前端入口弃用清单

本清单用于防止旧页面、重复运行时和无入口实现再次进入正式产品。路由、菜单和测试都应以“替代入口”为准。

| 已弃用入口或实现 | 替代入口 | 当前处理 | 删除或复核日期 |
| --- | --- | --- | --- |
| `/process/form/:nodeId` 与 `FormDesign.vue` | `/entity-form/design/:id`，流程节点只负责选择已发布表单 | 路由和文件已删除 | 2026-07-25 |
| `/entity/data/:code` 旧数据管理实现 | `/entity-list/:entityCode/:listKey` | 旧地址仅做可观测重定向，旧页面已删除 | 2026-10-31 复核旧地址访问量 |

| `EntityFormManage.vue` | `/entity-form/list-by-entity/:entityId` | 无正式路由，页面已删除 | 2026-07-25 |
| `ProcessDetail.vue` | `useProcessDetail` 与审批详情分区组件 | 无引用，旧组件已删除 | 2026-07-25 |

## 约束

- `src/views` 顶层页面必须有正式路由；可复用子视图应放入明确的组件目录。
- 旧地址只允许跳转到唯一运行时，不得复制查询、权限、表单或动作逻辑。
- 删除日期到期前应检查访问日志；无流量后删除兼容重定向。
- 页面配置测试会阻止本清单中已删除的文件重新出现。
