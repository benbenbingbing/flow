# 关联内容作为特殊表单属性的融合设计

本方案按最新要求修订并已落实到表单设计器：关联表单、关联列表、组成子表单和明细编辑，统一作为特殊属性对象。子表单目标与关联业务设置继续在关联配置中维护；子页面自身的展示、参数及加载设置归入当前属性抽屉的“子页面”，外层显示与布局复用当前属性面板。校验、事件和扩展按对象已支持的能力呈现，实际实现范围及测试见第 9 节。

## 1. 总体模型

设计器支持普通字段、布局容器和关联属性三类对象。关联属性引用已定义的实体关系及目标页面，并拥有本页面自己的显示、布局和交互设置。

关联属性按作用范围组织配置，但只有一个对象、一份编辑草稿：

- **通用设计属性**：当前属性面板维护外层显示名称、标题、可见性、位置、容器布局和区域外观，以及对象实际支持的校验、事件和扩展。
- **关联业务配置**：关联配置维护引用关系、目标子表单或列表、允许动作、动作回填和业务保存方式。
- **子页面专属配置**：当前属性抽屉的“子页面”维护子表单或子列表自身的展示、参数及加载行为；按目标类型组织对应设置，不混入外层通用布局。

“特殊表单属性”是设计器中的选择和编辑模型，不要求新增 `SUB_FORM`、`SUB_LIST` 实体字段。实体关系仍在实体设计中定义一次；表单中的关联属性是该关系的一个页面使用实例，不能独立修改外键、基数、所有权和级联规则。

同一个实体关系可以在不同表单中分别使用，各页面实例的名称、位置和展示方式独立维护。实例身份使用稳定键，改显示名称不改变关系身份、参数绑定或按钮引用。

## 2. 界面与入口

继续使用当前完整属性抽屉，保留原有五个页签和“子页面”名称。“关联配置”作为子页面页签内的业务配置区，与“子表单配置”“子列表配置”等专属设置区分组呈现：

| 属性页签 | 职责 |
| --- | --- |
| 基础与布局 | 当前对象外层的名称、显示、展示方式、位置和容器布局 |
| 数据校验 | 当前对象适用的字段或集合规则，不复制目标表单内部字段规则 |
| 联动与事件 | 当前对象支持的通用联动、生命周期事件及事件绑定 |
| 子页面 | 关联业务配置，以及子表单/子列表各自的展示选项、编辑布局、参数和加载设置 |
| 数据与扩展 | 当前对象的通用扩展、展示组件及相关参数 |

普通字段或容器保留其适用属性。关联属性按实际能力显示设置卡片，不因普通关联或组成关系整页禁用。没有适用内容的页签可显示简短说明，不堆砌大面积灰色控件。

### 入口行为

“＋节点”只提供布局、说明文本和动作插槽。关联表单／列表、子表单／明细编辑从左侧“实体关系”添加和配置，移除节点菜单中重复的跳转入口。

| 用户入口 | 默认打开位置 |
| --- | --- |
| 双击画布中的关联标题 | 当前属性抽屉 → 基础与布局 |
| 双击左侧已添加的关系标题 | 当前属性抽屉 → 基础与布局 |
| 点击左侧“已添加 · 配置” | 当前属性抽屉 → 子页面 → 关联配置 |
| 点击画布“配置” | 当前属性抽屉 → 子页面 → 关联配置 |
| 表单设置 → 关联内容 → 编辑 | 当前属性抽屉 → 子页面 → 关联配置 |
| 未添加的关系 → 添加 | 选择关系和目标页面，建立本地草稿对象，进入子页面中的关联配置区 |

标题双击和配置按钮只决定默认页签，不切换为另一个编辑对象，也不从服务端重新加载并覆盖当前未保存修改。Tab 和区块内的关联事件须转发到当前关联对象，不冒泡打开外层容器属性。

当前只有显示名称和标题开关的独立关联属性抽屉，应由完整属性抽屉替代。关系展示的三步向导拆出业务配置组件，放入“子页面 → 关联配置”；子表单和子列表自身的展示设置放入对应专属配置区。所有入口复用同一编辑对象，不再让用户在三套编辑表单之间重复修改。

## 3. 通用属性、关联业务与子页面配置的边界

| 配置项 | 唯一编辑位置 | 说明 |
| --- | --- | --- |
| 显示名称、显示标题 | 基础与布局 | 字段、关联区域和子表单统一呈现名称设置；删除重复的“配置名称/关联名称”输入 |
| 当前关联项启用/停用 | 基础与布局 | 沿用现有启用语义，与目录快捷操作同步到同一草稿 |
| 条件显示、运行模式显示 | 基础与布局 | 通用显示能力；普通关联已贯通配置协议、保存校验与运行时 |
| 嵌入、Tab、弹窗、抽屉、全屏打开 | 基础与布局 → 展示方式 | 普通关联保留五种方式；弹窗、抽屉、全屏通过根部入口打开，只有 Tab 的表单也保留“基本信息”承载入口；不改变保存方式。主从编辑只提供其运行时支持的方式 |
| 父容器/放置位置、顺序、栅格宽度、外层容器高度、边距和外观 | 当前属性抽屉 → 基础与布局 → 布局与层级 | 只控制关联区域在主表单中的摆放和外观，不包含子列表自身的最大高度 |
| 列表是否显示查询、分页、工具栏、操作列及每页条数 | 当前属性抽屉 → 子页面 → 子列表配置 | 属于子列表自身的展示选项；显示按钮不赋予业务动作权限 |
| 子列表最大高度、列表区域滚动等已支持的列表展示选项 | 当前属性抽屉 → 子页面 → 子列表配置 | 与分页等列表选项一起维护；与主表单外层容器高度分开 |
| 当前引用的实体关系、关联方向 | 当前属性抽屉 → 子页面 → 关联配置 → 关系引用 | 新增时选择关系；已有实例切换关系需明确重置不兼容绑定，不能隐式转换 |
| 目标实体、数量、外键、所有权及级联规则 | 当前属性抽屉 → 子页面 → 关联配置 → 关系摘要 | 本页只读，修改跳转实体设计 |
| 子表单、关联表单、关联列表的目标页面 | 当前属性抽屉 → 子页面 → 关联配置 → 目标内容 | 目标选择继续属于关联业务设置，按基数和使用方式选择已发布页面；专属配置区只显示当前目标摘要，不再重复选择 |
| 子表单/明细的分行或表格编辑布局 | 当前属性抽屉 → 子页面 → 子表单配置 | 配置子页面自身的编辑形态，与主页面的栅格宽度和容器布局分开 |
| 页面输入参数、子字段初始值、子列表查询参数 | 当前属性抽屉 → 子页面 → 对应子表单/子列表配置 → 参数传递 | 作为子页面运行配置，分别沿用普通关联与主从参数合同；不重复关联动作的回填与新增映射 |
| 按需/立即加载、无匹配记录提示 | 当前属性抽屉 → 子页面 → 对应子表单/子列表配置 → 加载与空状态 | 控制当前子页面实例的加载和空状态，按实际组件能力显示 |
| 查看、选择、新增、编辑、建立/解除关联 | 当前属性抽屉 → 子页面 → 关联配置 → 允许操作 | 根据目标、关系方向、所有权和服务端能力提供操作 |
| 选择结果回填、关联新增动作的初值、操作后处理 | 当前属性抽屉 → 子页面 → 关联配置 → 操作配置 | 与对应关联动作一起配置，和子页面的输入参数及子字段初值合同区分 |
| 关联操作的扩展接口、输入输出映射、失败策略 | 当前属性抽屉 → 子页面 → 关联配置 → 操作扩展 | 与关联动作绑定，不在通用数据源区再次配置一遍 |
| 当前对象的通用事件绑定 | 联动与事件 | 只展示对象已注册的事件；关联对象不能直接套用文本字段的失焦事件 |
| 自定义关联展示组件、组件参数、展示失败处理 | 数据与扩展 | 复用当前扩展界面，按关联内容上下文校验组件适用范围 |
| 普通字段的格式、唯一性及跨字段规则 | 数据校验 | 保持当前字段规则，不套用到整个关联区域 |
| 子表单内部字段规则 | 目标子表单设计器 | 主表只引用其已发布规则，不维护第二份子字段校验 |
| 明细集合规则 | 数据校验 | 仅主从组件实际支持的集合规则；新增规则须贯通保存与提交校验 |
| 随主表保存/独立保存 | 当前属性抽屉 → 子页面 → 关联配置 → 保存方式摘要 | 显示实际规则及适用限制，不提供无效的“随主表保存”勾选项 |

关联配置解决“连接谁、用什么页面、允许什么关联操作”；基础与布局解决“外层区域在主表单中如何显示和摆放”；子表单/子列表配置解决“子页面内部如何展示、加载和接收参数”。每个设置只在一个位置编辑。

### 子页面专属配置的统一归属规则

控制子页面内部展示或运行行为的选项，应放入“当前属性抽屉 → 子页面”下对应的配置区：

- **子列表配置**：查询、分页、工具栏、操作列、每页条数、列表最大高度，以及该组件已经支持的内部列表展示选项。
- **子表单配置**：分行/表格编辑形态，以及该组件已经支持的内部表单展示选项。
- **对应子页面的参数与加载配置**：页面输入参数、子字段初值、查询参数、加载时机和空状态提示。

这些设置仅作用于当前引用实例，不修改目标表单或列表自身的发布定义。普通关联列表和组成明细按各自组件能力呈现专属设置，不能因界面分组相同就互换配置协议或保存方式。未来新增同类选项也按这一规则归属，不再放到“基础与布局”。

## 4. 关联配置保留的实际功能

表单设置中的“关联内容”仍是新增和管理入口，保留配置目录、编辑、定位、停用、删除和状态展示。进入编辑后打开统一属性抽屉的“子页面 → 关联配置”，完整维护关联业务设置。

它不再维护第二份显示名称、标题、区域布局、子页面专属选项和组件参数；子页面中的关联业务配置区保留以下卡片：

1. **关系引用**：关系选择与只读摘要，包含实际关联方向、目标实体和保存方式。
2. **目标内容**：关联表单、关联列表、组成子表单或明细编辑使用的已发布目标页面。
3. **允许操作与回填**：查看、选择、新增、编辑、建立/解除关联，以及相关动作映射。
4. **操作扩展**：关联动作使用的受控接口与失败处理，默认折叠。

同一子页面页签内另有“子表单配置”“子列表配置”，分别承载编辑布局、列表展示、参数传递、加载与空状态。关联业务卡片与子页面专属卡片读取同一目标和草稿，不重复存储或编辑目标选择。

组成子表单同样从左侧关系入口和关联内容入口配置，不再依赖实体中出现子表单类型字段。关系目录应识别当前组成节点是否已添加，编辑同一个节点，不能再次创建独立展示配置。

扩展页面保持明确类型：当前记录另一张页面或受控接口页面。它可以复用关联属性的设计体验，但不显示不存在的实体关系信息，也不绕过关系匹配或数据权限。

## 5. 能力与数据行为

统一选择模型中的关联属性包括关联表单、关联列表、组成子表单和组成明细。显示与布局按对象能力共享，写入能力按真实数据语义校验。

| 使用方式 | 目标配置 | 实际业务数据保存 |
| --- | --- | --- |
| 普通关联表单 | 已发布表单、参数、允许的关联动作 | 目标记录独立保存；主页面取消不回滚已提交的目标记录 |
| 普通关联列表 | 已发布列表、参数、列表显示及允许动作 | 按目标列表和受控动作处理 |
| 组成子表单 | 已发布子表单、初值、编辑布局 | 子数据进入主表草稿，随主表提交 |
| 组成明细 | 已发布子记录表单、参数、编辑布局 | 明细集合随主表提交 |
| 组成关系的只读展示 | 已发布页面与展示参数 | 展示入口不承接独立写入，编辑仍通过主从组件 |

“组成关系”继续用于约束子数据生命周期，不用于阻断显示名称、标题等通用属性。只读展示不因勾选一个编辑开关变成聚合编辑；普通关联也不因打开属性页变成主表拥有的子数据。

目标数据是否可操作仍需校验目标实体、记录、字段、关系和动作权限。条件显示或隐藏操作列只改变页面呈现，不扩大权限。

## 6. 一份草稿与统一保存

- 设计器维护统一的选中对象和本地编辑状态。常规属性、子页面专属设置及关联业务配置修改同一个对象，切换页签、入口或关闭抽屉均保留本地修改。
- “保存当前”保存当前特殊属性的设计、子页面和关联部分，不允许只保存名称而漏掉目标、分页选项或参数。
- “保存全部”覆盖表单元数据、普通节点、组成节点和普通关联配置；发布前处理本地未保存修改，失败则停止发布。
- 当前项的恢复操作、整表撤销、刷新重载和冲突处理都读取同一份基线。
- 新增、删除及停用也进入这一草稿，目录和画布立即同步；发布后运行时生效。
- 设计配置的保存统一，不改变业务记录的独立保存或主从提交规则。

现有接口可以先复用，但各次保存必须使用最新宿主修订号，并保留失败项及脏状态。跨多接口保存失败不能提示全部成功。最终可采用事务内整表草稿保存能力，统一预检和提交；不要求为了合并界面先改数据库存储。

## 7. 对现有代码的适配设计

### 统一属性上下文

当前属性代码主要以选中的节点字段为上下文。应抽取统一上下文，至少包含对象身份、对象类型、适用能力、草稿、基线和保存适配器。

- 普通字段/容器适配现有节点编辑模型。
- 组成子表单/明细仍适配真实关系绑定节点；目标子表单由关联业务组件选择，参数与编辑布局由子页面内对应的专属组件编辑。
- 普通关联表单/列表适配现有关联内容记录。新增关系属性对象只表达页面实例，不伪造成实体字段。
- 同一上下文同时供通用属性区、子页面专属配置区和关联业务配置区使用，替换当前独立关联属性抽屉。

关联配置组件不感知自己来自标题双击、目录编辑还是侧栏配置，也不在切换入口时立即独立保存。

### 保留现有存储语义

界面与草稿先统一，节点和关联记录仍由各自适配器序列化：

- 名称：普通关联优先读取 `presentation.title`，兼容 `config.name`；组成节点使用节点标签。界面只保留一个显示名称输入。
- 标题开关：普通关联映射 `presentation.showTitle`，组成节点映射 `subFormConfig.showTitle`。历史缺省值继续显示标题。
- 目标和参数：普通关联映射其目标及页面参数；组成节点映射稳定子表单引用与现有主从参数合同。目标选择与参数编辑虽处于不同配置区，仍写入同一个对象。
- 子页面专属选项：列表分页、工具栏、操作列、每页条数及最大高度等由子列表适配器序列化；子表单内部编辑布局由子表单适配器处理，不混入外层容器布局字段。
- 位置：普通关联的 `anchorKey` 是挂载点，组成节点的 `parentId` 是树父节点。统一位置选择体验，但不得直接互换存储字段；保存与重载需保持节点内/节点后、Tab 内等真实语义。
- 关联实例键、节点键和关系标识保持稳定。切换目标页面后验证参数与动作兼容性，并明确提示需调整的配置。

### 能力支持边界

当前普通关联已整合名称、标题、目标、位置、加载、参数及受控操作。以下能力必须贯通协议及运行时，不能仅显示字段控件：

- 条件显示、运行模式显示：本次已支持普通关联区域，沿用结构化条件，不影响数据或动作权限。
- 区域宽度、外层高度和内边距：本次已支持受限数值布局，不接受任意 CSS；其他外观项按已有节点能力呈现。
- 普通关联列表的查询、分页、工具栏、操作列、每页条数及最大高度：本次已贯通保存校验和运行时传递。
- 通用关联事件：仍需先注册对象适用的事件合同及执行入口；当前页签解释使用边界，选择回填、新增映射及操作扩展仍在关联操作中维护。
- 整表脏状态、统一保存和撤销：本次已覆盖节点和普通关联记录；多接口保存保留成功基线与失败草稿。

## 8. 实施阶段与验收

1. **合并对象和入口。** 统一选中上下文，替换独立的小属性抽屉，保留五个页签和“子页面”名称。双击定位基础与布局，配置按钮定位子页面中的关联配置区，均不丢草稿。
2. **重新归属已有配置。** 关系、目标子表单/列表和关联动作放进关联业务配置区；查询、分页、工具栏、操作列、每页条数、列表最大高度、子表单编辑布局、页面参数及加载放进子页面对应专属配置区；外层名称、标题、展示方式和位置放回常规属性。各类型按能力复用组件。

## 9. 本次实现与验证

### 已实现

- 表单设计器所有普通关联入口复用五页签属性抽屉。双击标题进入基础与布局，配置/目录编辑进入子页面；原来只有名称和标题的独立抽屉已移除。
- 子页面分组呈现关联配置、子表单/子列表配置、关联操作及操作扩展。目标页面在关联配置中选择，子列表展示开关、每页条数、最大高度、页面参数、加载方式及空状态提示在专属配置区编辑。
- 组成关系仍生成真实主从节点，目标子表单选择归入关联配置，显示名称/标题归入基础与布局，内部编辑布局与参数归入子页面，不引入新的实体字段类型。
- 各入口共用本地草稿，关闭抽屉保留输入。保存当前只提交当前关联对象；保存全部处理表单、节点和关联对象，发布先保存未保存修改。部分失败保留待重试项，不提示全部成功。
- 新增、更新和删除顺序使用最新宿主修订号；新增请求提供修订号时后端也会检查。已发布表单的纯本地修改/删除可以撤销，无需调用服务端发布草稿回退。
- 普通关联的条件显示、运行模式显示和外层尺寸在运行时生效。子列表的最大高度与外层容器高度分别保存、分别渲染；展示开关不扩大目标权限。
- 普通关联表单在当前区域直接编辑，统一使用“保存子表单”，移除原来的刷新、编辑、新增按钮。已有记录执行更新；尚无记录且服务端允许新增时显示新增草稿，第一次保存创建记录。组成子表单继续随主表提交。
- 独立保存复用已发布表单校验、数据源提交预检、服务端创建初值和带关联凭证的原生提交接口。权限不足或发布表单只读时保持只读；失败保留输入，成功自动重新解析并加载记录。新增后的关系匹配沿用既有新增初值映射，不额外修改主表关系字段。
- 子表单草稿不进入主表数据模型。主表映射参数变化时保留正在编辑的草稿；提交期间锁定当前区域，防止重复提交。切换来源记录后，旧请求的回包不能覆盖新记录。
- 主表弹窗关闭、页面离开及刷新前保护独立子表单草稿。保存主表后如仍有子表单未保存内容，保留弹窗供继续保存；主表保存不能将子表单草稿标为已保存。

### 保持的能力边界

- 普通关联的目标记录仍独立保存，组成子表单和明细仍随主表提交；融合属性界面不改变数据所有权。
- 目标子表单内部字段校验由目标表单维护。普通关联区域没有已注册的通用字段事件，相关页签显示说明；现有关联动作、回填和扩展接口仍可配置。
- 通过关联内容加载的目标表单不继续渲染其自身的关联内容（包括根级、字段及 Tab 挂载入口），避免主子表相互引用后重复打开。不提供开启嵌套关联展示的设置。隔离仅作用于当前加载的表单投影，不修改目标发布配置；目标表单独立打开时保留自己的关联入口。
- 本次范围为表单设计器。独立列表设计器继续兼容既有向导及接口；后续可复用相同编辑分组，不需要改变关联记录存储。

### 节点整体显示规则

节、区块、栅格、Tab 集合、Tab 页、折叠面板、说明文本、动作插槽及组成子表单/明细均可在“基础与布局”配置运行模式显示和条件显示。四种模式（新增、编辑、查看、审批）的显示开关与条件显示同时满足时，整个节点及其内部内容才显示；隐藏不清空已填写数据。

布局节点只提供显示配置，不提供字段的“可编辑”“条件禁用”和“条件必填”。父节点隐藏时子节点及锚定关联区域一并隐藏，栅格不留空列；当前 Tab 隐藏后自动选择可见页签。前端校验跳过隐藏区域内的字段，服务端数据权限与实体约束继续独立校验。显示配置存于节点属性，无需数据库迁移。
