# 表单与列表运行时：业务上下文与配置摘要

表单、列表和关联内容不再签发配置解析令牌。请求、响应及 PC/移动端共享运行时使用稳定业务身份；没有配置令牌有效期、父子令牌传递、续期器或令牌失效重试。登录、OAuth、Embed 会话以及 Excel 操作凭证继续承担各自的认证和动作授权职责。

## 请求约定

- 表单加载返回 `formId`、`configHash`、`runtimeContext`。事件、按钮及数据源提交表单身份与同一摘要；实体保存/审批的扁平请求使用 `formConfigHash`。
- 列表加载返回 `configHash`、`runtimeContext`。列表查询和动作提交业务列表标识；扁平新建请求用 `listConfigHash`。
- `runtimeContext` 是普通业务定位对象，不是凭证。任务入口使用 `taskId`，只读流程入口使用 `processInstanceId` 和节点定位；后端重新读取实际待办、记录、节点表单绑定和访问权限。
- 子表单使用根表单/根记录和组件路径；后端逐层核验已发布组件引用及实际父子记录关系。新建子行不携带伪造的持久化记录 ID。
- 关联内容使用 `compositionContext`（根 owner、来源记录、关联编码及路径）。列表候选请求的 `candidateAction` 仍须通过对应动作权限检查，固定筛选与用户查询取交集。
- GET 参数中的上下文用 JSON 编码；服务端解码后仍视为不可信输入。

## 行为边界

`configHash` 无签名、无有效期，也不能用于选择历史配置。表单摘要覆盖嵌套依赖；写操作在执行事件、Provider 或数据变更之前检查摘要。配置变化返回冲突提示，前端保留输入，不自动重放写请求。一个已受理请求/事务内复用已解析的配置。

审批提交的任务和记录由实时待办确定；任务已完成、转办或无办理身份时拒绝。历史参与人继续使用流程读取权限，但不能借只读入口执行写 Provider。

Embed 保留现有会话认证。原生请求由服务端会话根入口、依赖关系和固定记录范围恢复授权，配置解析不再额外签发令牌。普通列表读取当前激活配置，Embed 和关联宿主已有的固定列表语义仍从服务端可信绑定恢复。

## 删除与存储

已移除原配置令牌签发/验证服务、关联内容签名服务、前端续期模块及对应导出、DTO 字段和旧测试；原表单/列表发布上下文结构改为配置摘要与业务定位结构。

原配置令牌属于运行时字段，不是独立数据库列。本次不新增、修改或删除 Flyway 迁移，不删除列表发布历史，也不改写历史迁移。现有流程无需为此次协议调整重新发布。前后端及自定义运行时扩展应同步更新，不继续发送旧配置令牌协议。
