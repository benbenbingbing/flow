# 子页面内置按钮外观

在表单设计器中选中子表单引用，进入「子页面 → 内置按钮外观」。按钮功能固定，配置仅影响当前引用的展示；目标子表单本身及其他引用不会被同步改写。

## 支持范围

- 普通关联表单：保存子表单，以及弹窗、抽屉、全屏的打开入口。
- 普通关联列表：当前形态已有的刷新、打开入口。
- 组成型子表单和明细：添加、删除；新增操作栏可移动，删除始终跟随对应数据行。
- 移动端组成子表单使用同一份外观配置，保留原有增删行和删除确认流程。移动端普通关联区域沿用原有只读能力。

可设置文案、图标、主题颜色、实心/朴素/文字/链接/圆角/圆形样式、尺寸，以及操作栏位置、对齐、间距和区域按钮排序。按钮明细默认折叠，点击标题栏的编辑入口后调整设置；面板提供实时按钮预览和恢复默认入口。

当前面板通过「主题颜色」和「按钮样式」控制外观，不再显示「文字颜色」「背景颜色」「边框颜色」「圆角」四个独立配置项。其中，圆角和圆形仍可通过按钮样式选择，不提供圆角数值输入。

## 固定业务约束

外观配置不接受显隐、启停、权限、事件或执行器字段。按钮的出现、可用状态、加载状态和点击处理仍由原宿主决定。普通关联子表单继续独立保存，组成型子表单继续随主表保存。上下双栏共用同一个保存状态和处理函数，不会引入新的提交路径。

无图标的圆形按钮回退到文字按钮；表格行删除清空图标时显示“删除”，避免空白入口。旧配置未设置外观时保留各端原有文案、图标、位置和样式。

## 配置存储

普通关联保存至 `config.presentation.actionBar`；组成型节点保存至 `componentProps.subFormConfig.actionBar`。示例：

```json
{
  "position": "BOTTOM",
  "align": "RIGHT",
  "gap": 8,
  "buttons": {
    "save": {
      "label": "保存验收信息",
      "icon": "Check",
      "buttonType": "primary",
      "buttonAppearance": "DEFAULT",
      "size": "default"
    }
  }
}
```

全部字段可省略。`position` 支持 `DEFAULT/TOP/BOTTOM/BOTH`，`align` 支持 `DEFAULT/LEFT/CENTER/RIGHT`；`DEFAULT` 采用当前宿主原有布局。按钮标识按类型限定为 `save/open`、`refresh/open` 或 `add/remove`。间距范围为 0–40，排序范围为 0–1000，文案最多 80 字符。服务端与前端均按字段白名单校验。

历史配置中的 `textColor`、`backgroundColor`、`borderColor` 和 `borderRadius` 继续由后端与运行时兼容读取，避免打开已有页面时改变外观。这些字段不再作为面板输入项；历史颜色仍仅接受十六进制，历史圆角数值仍限制为 0–40。用户重新选择主题颜色时清除当前按钮的旧三色覆盖，重新选择按钮样式时清除旧圆角数值，使新选择能够生效。

切换关联目标类型时清理不适用按钮设置并保留共用打开入口和布局；只切换嵌入、弹窗等展示方式时保留配置，便于切回。恢复默认只清除外观覆盖，不修改业务数据。

本功能复用现有 JSON 配置存储，不涉及数据库迁移；迁移文件新增、修改、删除均为无。
